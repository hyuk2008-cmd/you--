Google Cloud Console에서 YouTube Data API v3를 활성화한 후 키를 발급받으세요. API 활성화 · 키는 이 브라우저 localStorage에만 저장됩니다.

mostPopular 차트는 음악·영화·게임 등에 편중될 수 있으며, YouTube 공식 전체 급상승 목록이 아닙니다. relevanceLanguage는 완벽한 언어 필터가 아니므로 다른 언어 영상이 섞일 수 있습니다. 시간당 조회수는 누적 조회수 ÷ 업로드 경과시간의 추정값입니다. 실제 최근 증가량은 이전 측정 기록이 있을 때만 표시됩니다.

언어·지역·카테고리는 검색 우선순위에 영향을 주며 완벽한 필터는 아닙니다. 스페인어(남미) 선택 시 지역을 멕시코 등으로 맞추면 남미 콘텐츠가 더 잘 나옵니다. 시사·정치는 News & Politics, 유머는 Comedy, 패션·뷰티는 Howto & Style 등 YouTube 공식 카테고리로 매핑됩니다.

YouTube 크리에이터용 무료 음원 · 효과음

YouTube Data API로는 Audio Library 음원을 일괄 다운로드할 수 없습니다. 아래는 공식 YouTube 오디오 라이브러리와 합법 무료 소스에서 분위기별로 찾기 쉽게 정리한 가이드입니다. 다운로드는 반드시 공식 페이지에서 진행하세요.

YouTube 스튜디오 오디오 라이브러리 youtube.com/audiolibrary Pixabay Music Pixabay SFX Freesound (라이선스 확인)

분위기별 무료 배경음악 (검색 키워드)

Audio Library / Pixabay에서 아래 영어 키워드로 검색하면 비슷한 분위기의 트랙을 빠르게 찾을 수 있습니다. 필터에서 Attribution not required(저작자 표시 불필요)를 우선 선택하세요.

자주 쓰는 효과음 (SFX)

숏폼·브이로그·설명 영상에서 반복적으로 쓰이는 효과음입니다. Audio Library의 Sound effects 탭 또는 Pixabay SFX에서 검색하세요.

실전 팁

  • 인트로 3~5초: whoosh / pop / notification 으로 시선 집중
  • 장면 전환: whoosh, swoosh, transition sweep
  • 강조·반전: impact, hit, bass drop (짧은 버전)
  • 브이로그 일상: soft ukulele, lo-fi, acoustic chill
  • 정보·뉴스 톤: corporate, documentary, minimal piano
  • 긴장·반전: dark ambient, suspense drone, ticking
  • 엔딩 CTA: upbeat short stinger 또는 soft resolve
  • 음량: 배경음악은 보통 -18 ~ -12 LUFS 근처, 보이스보다 작게
  • 저작권: YouTube 오디오 라이브러리 트랙은 스튜디오에서 받은 라이선스 조건을 따름. 타 사이트는 트랙마다 라이선스가 다름

상단에서 모드를 선택하고 탐색/검색을 시작하세요.

급상승 모드는 검색어 없이 조회수 속도가 빠른 후보 영상을 찾습니다.
